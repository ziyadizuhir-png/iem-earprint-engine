GENERAL PROMPT EARPRINT 8
MATH-LOCKED BOUNDARY HANDOFF ADDENDUM
ENGINEERING LOCKED VERSION 3.3.0


======================================================================
1. PURPOSE
======================================================================

This addendum defines the locked mathematical boundary behaviour between:

    BaseTarget

and

    Masked EarPrint

inside the personal EarPrint frequency domain.

The boundary handoff is a deterministic mathematical operation.

It must not be treated as:

    - a subjective tuning preference
    - a target preference
    - a psychoacoustic optimisation
    - a target ranking
    - a curvature-minimisation problem
    - a weighted multi-objective optimisation problem

The purpose of the handoff is strictly geometric:

    preserve the selected BaseTarget through the fixed nominal anchor,
    transition smoothly into the Masked EarPrint,
    and prevent artificial discontinuities, overshoot, extrema,
    oscillation or slope reversal.


======================================================================
2. INPUT DEFINITIONS
======================================================================

The handoff operates on three aligned arrays:

    freq[i]

    BaseTarget[i]

    MaskedEarPrint[i]

All three arrays MUST:

    - use the same frequency grid
    - be strictly increasing in frequency
    - contain finite numerical values
    - use logarithmic-frequency geometry for slope and transition calculations


The Masked EarPrint is assumed to have already been generated upstream.

This addendum does NOT redefine:

    - target construction
    - EarPrint construction
    - robust-mask estimation
    - Huber estimation
    - alignment
    - smoothing
    - cross-IEM consensus


======================================================================
3. FIXED HANDOFF ANCHOR
======================================================================

The handoff anchor is permanently fixed at:

    H = 1000 Hz


The 1000 Hz point is a computational anchor.

It is not an adaptive variable.

The engine MUST NOT search for an alternative H.

Therefore:

    H = 1000 Hz

is locked for all target families.


======================================================================
4. BASETARGET PRESERVATION
======================================================================

BaseTarget MUST be preserved exactly through H.

For:

    f <= H

the output MUST be:

    Output(f) = BaseTarget(f)


No Masked EarPrint correction may be introduced below or at H.


======================================================================
5. TRANSITION ENDPOINT E
======================================================================

The transition endpoint E is searched above H.

The permitted transition width is:

    1/3 octave <= log2(E / H) <= 0.8 octave


Therefore:

    E_min = H * 2^(1/3)

    E_max = H * 2^0.8


The search MUST proceed in ascending master-grid frequency order.


======================================================================
6. E SELECTION RULE
======================================================================

E selection is strictly:

    EARLIEST FEASIBLE E


The first candidate E that passes every mandatory hard gate MUST be selected.

A later E MUST NOT replace an earlier feasible E because it has:

    - lower curvature
    - better numerical score
    - smaller slope mismatch
    - a more attractive shape
    - a preferred psychoacoustic interpretation
    - a better target-specific outcome


======================================================================
7. PROHIBITED E OPTIMISATION
======================================================================

The locked implementation MUST NOT use:

    - weighted candidate scores
    - Pareto fronts
    - curvature minimisation
    - target-specific ranking
    - subjective preference functions
    - hand-tuned candidate weights
    - arbitrary penalty functions
    - hidden secondary optimisation


The selection decision is binary:

    feasible

or

    not feasible


Among feasible candidates:

    earliest E wins.


======================================================================
8. TRANSITION VARIABLE
======================================================================

For:

    H < f <= E

define:

    t = log2(f / H) / log2(E / H)


Therefore:

    t = 0    at H

    t = 1    at E


The transition variable MUST be constrained to:

    0 <= t <= 1


======================================================================
9. LOCKED TRANSITION FUNCTION
======================================================================

The transition MUST use the quintic smootherstep:

    w(t) = 6t^5 - 15t^4 + 10t^3


The final transition is:

    Output(f)
        =
    BaseTarget(f)
        +
    w(t)
    *
    (
        MaskedEarPrint(f)
        -
        BaseTarget(f)
    )


This is the only locked transition function.


======================================================================
10. EXACT SMOOTHERSTEP PROPERTIES
======================================================================

The locked quintic function satisfies:

    w(0) = 0

    w(1) = 1


Its first derivative is:

    w'(t)
        =
    30t^4 - 60t^3 + 30t^2


Therefore:

    w'(0) = 0

    w'(1) = 0


Its second derivative is:

    w''(t)
        =
    120t^3 - 180t^2 + 60t


Therefore:

    w''(0) = 0

    w''(1) = 0


For:

    0 <= t <= 1

the function satisfies:

    0 <= w(t) <= 1

and:

    w'(t) >= 0


This guarantees a monotonic transition weight.


======================================================================
11. C1 BOUNDARY CONDITION
======================================================================

At H:

    w(0) = 0

    w'(0) = 0


Therefore the transition begins from BaseTarget without an imposed
transition-weight slope discontinuity.

At E:

    w(1) = 1

    w'(1) = 0


Therefore the transition arrives at Masked EarPrint without an imposed
transition-weight slope discontinuity.


The smootherstep boundary conditions are mathematical properties of the
weight function.

They MUST NOT be interpreted as a guarantee that arbitrary source curves
are globally monotonic.


======================================================================
12. HARD BRIDGE GATES
======================================================================

Every candidate E MUST pass all mandatory bridge gates.


12.1 FINITE VALUES

The complete bridge MUST contain only finite values.

Reject candidate if:

    NaN

or:

    +Inf

or:

    -Inf

appears anywhere in the bridge.


12.2 MONOTONICITY

The bridge MUST preserve one monotonic direction between its endpoint levels.

If:

    Output(E) > Output(H)

then the bridge must not contain a negative local slope.

If:

    Output(E) < Output(H)

then the bridge must not contain a positive local slope.


12.3 NO OVERSHOOT

The bridge MUST remain inside the endpoint level interval.

Let:

    L = min(Output(H), Output(E))

    U = max(Output(H), Output(E))


Then:

    L <= Output(f) <= U


must hold throughout the transition.


12.4 NO UNDERSHOOT

No bridge sample may fall below the lower endpoint level.


12.5 NO ARTIFICIAL EXTREMA

The bridge MUST NOT create an artificial local maximum or minimum.

Repeated slope-sign reversal is a hard failure.


12.6 NO SLOPE REVERSAL

The bridge MUST NOT reverse its overall transition direction.


======================================================================
13. DESTINATION STABILITY
======================================================================

The destination region immediately after E must be geometrically stable.

A destination candidate must satisfy:

    - stable local slope direction
    - no pathological repeated curvature oscillation


The destination stability window is:

    0.20 octave


A candidate with insufficient samples for a meaningful stability decision
must be rejected.


======================================================================
14. CURVATURE RULE
======================================================================

Curvature is used only as a HARD STABILITY GATE.

Curvature MUST NOT be used to rank otherwise feasible candidates.


A smooth curve may contain one natural curvature sign crossing.

Therefore:

    one curvature sign crossing

does NOT automatically mean instability.


Repeated alternating curvature behaviour is treated as instability.


======================================================================
15. MASTER-GRID RULE
======================================================================

Candidate E values MUST come from the actual master frequency grid.

The engine MUST NOT invent an arbitrary continuous E between master-grid
samples for the purpose of selecting the transition endpoint.


The selected E is therefore deterministic for a fixed master grid.


======================================================================
16. REGION DEFINITIONS
======================================================================

The final output has exactly three conceptual regions.


REGION A:

    f <= H

Output:

    BaseTarget


REGION B:

    H < f <= E

Output:

    BaseTarget
    +
    smootherstep
    *
    (
        MaskedEarPrint
        -
        BaseTarget
    )


REGION C:

    f > E

Output:

    MaskedEarPrint


No additional correction or blending operation is allowed after E.


======================================================================
17. FAIL-SAFE
======================================================================

If no candidate E satisfies every mandatory hard gate:

    status = NO_STABLE_HANDOFF


The engine MUST then return:

    BaseTarget


No forced transition is permitted.

The engine MUST NOT:

    - relax the gates automatically
    - extend the transition beyond 0.8 octave
    - select an arbitrary fallback E
    - invoke a secondary optimisation
    - force a seam because a result is desired


Failure to find a valid handoff is preferable to introducing a
mathematically invalid transition.


======================================================================
18. DETERMINISM
======================================================================

For identical:

    - frequency grid
    - BaseTarget
    - Masked EarPrint
    - configuration

the engine MUST produce the same:

    H

    E

    output

    diagnostics

on every run.


No randomisation is permitted.

No target-specific hidden parameter is permitted.


======================================================================
19. VERTICAL TRANSLATION INVARIANCE
======================================================================

Adding a constant vertical offset C to both source curves:

    BaseTarget' = BaseTarget + C

    MaskedEarPrint' = MaskedEarPrint + C


must not alter:

    H

    E

    transition width

    slope geometry

    curvature geometry

    candidate feasibility


The resulting output must satisfy:

    Output' = Output + C


within numerical precision.


======================================================================
20. POSITIVE SCALE INVARIANCE
======================================================================

Multiplying both source curves by a positive constant A:

    A > 0


must preserve the geometric decision:

    H

    E

    transition width

    feasibility


The output must scale consistently:

    Output' = A * Output


within numerical precision.


======================================================================
21. NEGATIVE SCALE
======================================================================

Negative scaling is not a physically meaningful dB-domain transformation
for this handoff and is therefore NOT part of the locked production
invariance contract.


======================================================================
22. NO STITCHING
======================================================================

The handoff MUST NOT be implemented by stitching together unrelated
target curves.

There is only one BaseTarget and one Masked EarPrint.

The transition is a continuous mathematical blend between those two
source curves.


======================================================================
23. NO TARGET AVERAGING
======================================================================

The handoff MUST NOT average:

    Harman
    JM-1

    Headphones.com IEM DF
    SoundGuys
    5128 DF

Target selection occurs upstream.

The handoff engine is target-agnostic.


======================================================================
24. NO PSYCHOACOUSTIC TARGET OPTIMISATION
======================================================================

Audiophile or psychoacoustic research may justify why smooth transitions,
spectral continuity and avoidance of artificial extrema matter.

However, such research MUST NOT be converted into hidden target-specific
selection weights inside the handoff algorithm.

The locked algorithm remains geometrical and deterministic.

26. LOCKED SELECTION DECLARATION

======================================================================
27. ENGINEERING RATIONALE
======================================================================

The architecture intentionally separates:

    SOURCE CONSTRUCTION

from:

    BOUNDARY HANDOFF


Source construction determines:

    BaseTarget

and:

    Masked EarPrint


Boundary handoff determines only how those two already-defined curves are
connected.


The locked handoff therefore does not attempt to determine what the target
should sound like.

It determines only whether and how the transition can be made without
introducing mathematically artificial behaviour.

======================================================================
31. FINAL MATHEMATICAL LOCK
======================================================================

The production boundary equation is:

    Output(f)
        =
    BaseTarget(f)
        +
    w(t)
    *
    (
        MaskedEarPrint(f)
        -
        BaseTarget(f)
    )


where:

    t
        =
    log2(f / 1000)
    /
    log2(E / 1000)


and:

    w(t)
        =
    6t^5
    -
    15t^4
    +
    10t^3


for:

    1000 < f <= E


with:

    1/3 <= log2(E / 1000) <= 0.8


and E selected as:

    the earliest master-grid candidate satisfying all hard gates.


For:

    f <= 1000

the output is exactly:

    BaseTarget


For:

    f > E

the output is exactly:

    Masked EarPrint


If no valid E exists:

    output = BaseTarget

    status = NO_STABLE_HANDOFF


This constitutes the locked boundary-handoff specification.
