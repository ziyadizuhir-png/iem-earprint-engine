GENERAL PROMPT EARPRINT 8
MATH-LOCKED BOUNDARY HANDOFF ADDENDUM
ENGINEERING LOCKED VERSION 3.4.0


======================================================================
1. PURPOSE
======================================================================

This addendum defines the locked mathematical boundary behaviour between:

    BaseTarget

and

    Masked EarPrint

inside the personal EarPrint frequency domain.

The boundary handoff is a deterministic mathematical operation.

It must not be treated as:

    - a subjective tuning preference
    - a target preference
    - a psychoacoustic optimisation
    - a target ranking
    - a curvature-minimisation problem
    - a weighted multi-objective optimisation problem

The purpose of the handoff is strictly geometric:

    preserve the selected BaseTarget through the fixed nominal anchor,
    connect it to the Masked EarPrint with a shape-preserving bridge,
    and prevent artificial discontinuities, overshoot, extrema,
    oscillation or slope reversal.


======================================================================
2. INPUT DEFINITIONS
======================================================================

The handoff operates on three aligned arrays:

    freq[i]

    BaseTarget[i]

    MaskedEarPrint[i]

All three arrays MUST:

    - use the same frequency grid
    - be strictly increasing in frequency
    - contain finite numerical values
    - use logarithmic-frequency geometry for slope and transition calculations

The Masked EarPrint is assumed to have already been generated upstream.

This addendum does NOT redefine:

    - target construction
    - EarPrint construction
    - robust-mask estimation
    - Huber estimation
    - alignment
    - smoothing
    - cross-IEM consensus


======================================================================
3. FIXED HANDOFF ANCHOR
======================================================================

The handoff anchor is permanently fixed at:

    H = 1000 Hz

The 1000 Hz point is a computational anchor.

It is not an adaptive variable.

The engine MUST NOT search for an alternative H.

If the original target grid does not contain an exact 1000 Hz sample,

    1000 Hz MUST be inserted only into the INTERNAL computational master grid
    by log-frequency interpolation.

The published output grid MUST remain the original target/output grid.

Therefore:

    H = 1000 Hz

is locked for all target families.


======================================================================
4. BASETARGET PRESERVATION
======================================================================

BaseTarget MUST be preserved exactly through H.

For:

    f <= H

the output MUST be:

    Output(f) = BaseTarget(f)

No Masked EarPrint correction may be introduced below or at H.


======================================================================
5. TRANSITION ENDPOINT E
======================================================================

The transition endpoint E is searched above H.

The permitted transition width is:

    1/3 octave <= log2(E / H) <= 0.8 octave

Therefore:

    E_min = H * 2^(1/3)

    E_max = H * 2^0.8

The search MUST proceed in ascending master-grid frequency order.

E MUST be selected from the master-grid samples.


======================================================================
6. E SELECTION RULE
======================================================================

E selection is strictly:

    EARLIEST FEASIBLE E

The first candidate E that passes every mandatory hard gate MUST be selected.

A later E MUST NOT replace an earlier feasible E because it has:

    - lower curvature
    - better numerical score
    - smaller slope mismatch
    - a more attractive shape
    - a preferred psychoacoustic interpretation
    - a better target-specific outcome


======================================================================
7. PROHIBITED E OPTIMISATION
======================================================================

The locked implementation MUST NOT use:

    - weighted candidate scores
    - Pareto fronts
    - curvature minimisation
    - target-specific ranking
    - subjective preference functions
    - hand-tuned candidate weights
    - arbitrary penalty functions
    - hidden secondary optimisation

The selection decision is binary:

    feasible

or

    not feasible

Among feasible candidates:

    earliest E wins.


======================================================================
8. TRANSITION VARIABLE
======================================================================

For:

    H < f <= E

define:

    t = log2(f / H) / log2(E / H)

Therefore:

    t = 0    at H

    t = 1    at E

The transition coordinate MUST satisfy:

    0 <= t <= 1


======================================================================
9. LOCKED TRANSITION FUNCTION
======================================================================

The production transition MUST use a single shape-preserving monotone cubic
Hermite bridge over the interval [H,E].

Let:

    Y0 = BaseTarget(H)

    Y1 = MaskedEarPrint(E)

    Delta = Y1 - Y0

    L = log2(E / H)

The bridge is a cubic Hermite polynomial in t:

    B(t) = c0 + c1*t + c2*t^2 + c3*t^3

with endpoint values:

    B(0) = Y0

    B(1) = Y1

The raw endpoint slopes are taken from the source curves in dB/octave:

    d0_raw = slope(BaseTarget, H)

    d1_raw = slope(MaskedEarPrint, E)

The raw endpoint slopes MUST be retained exactly. They MUST NOT be clipped,
scaled, direction-limited, or otherwise altered before bridge construction.

The normalized endpoint derivatives are:

    alpha = d0_raw * L / Delta

    beta  = d1_raw * L / Delta

A candidate is feasible only when:

    alpha >= 0

    beta >= 0

    alpha + beta <= 3

If any of these conditions fails, the candidate E MUST be rejected. The
engine MUST NOT repair the candidate by changing either endpoint slope.

The bridge MUST then be validated with an exact analytic derivative test.
This makes TRUE-C1 continuity a feasibility requirement rather than a
post-construction smoothing operation.


======================================================================
10. EXACT MONOTONE CUBIC CONDITION
======================================================================

For the cubic Hermite bridge:

    B'(t) = c1 + 2*c2*t + 3*c3*t^2

The derivative is a quadratic.

The production validator MUST examine:

    - t = 0
    - t = 1
    - every real derivative root strictly inside (0,1)

The sign of every meaningful derivative sample MUST agree with the endpoint
transition direction.

This analytic root check is authoritative for monotonicity.

A sampled derivative grid alone is not considered sufficient.


======================================================================
11. ENDPOINT-DIRECTION COMPATIBILITY
======================================================================

The bridge MUST NOT hide a genuine source-curve slope reversal at H or E.

If:

    Delta > 0

then meaningful source endpoint slopes must not be negative.

If:

    Delta < 0

then meaningful source endpoint slopes must not be positive.

A candidate violating either endpoint-direction rule MUST be rejected.

This prevents the bridge from fabricating monotonic behaviour by flattening
an endpoint whose source geometry points in the opposite direction.


======================================================================
12. HARD BRIDGE GATES
======================================================================

Every candidate E MUST pass all mandatory bridge gates.

12.1 FINITE VALUES

The complete bridge MUST contain only finite values.

12.2 MONOTONICITY

The bridge MUST preserve one monotonic direction between its endpoint levels.

12.3 NO OVERSHOOT

The bridge MUST remain inside the endpoint level interval.

Let:

    L = min(Output(H), Output(E))

    U = max(Output(H), Output(E))

Then:

    L <= Output(f) <= U

throughout the transition.

12.4 NO UNDERSHOOT

No bridge value may fall below the lower endpoint level.

12.5 NO ARTIFICIAL EXTREMA

The bridge MUST NOT create a local maximum or minimum that is not required
by the endpoint geometry.

12.6 NO SLOPE REVERSAL

The bridge MUST NOT reverse its overall transition direction.

12.7 CONTINUITY

The bridge endpoints MUST equal the required source levels within the locked
numerical tolerance.


======================================================================
13. DESTINATION STABILITY
======================================================================

The destination region immediately after E must be geometrically stable.

A destination candidate must satisfy:

    - stable local slope direction
    - no pathological repeated curvature oscillation

The destination stability window is:

    0.20 octave

A candidate with insufficient samples for a meaningful stability decision
must be rejected.


======================================================================
14. CURVATURE RULE
======================================================================

Curvature is used only as a HARD STABILITY GATE.

Curvature MUST NOT be used to rank otherwise feasible candidates.

A smooth curve may contain one natural curvature sign crossing.

Repeated alternating curvature behaviour is treated as instability.


======================================================================
15. MASTER-GRID RULE
======================================================================

Candidate E values MUST come from the actual computational master grid.

The engine MUST NOT invent an arbitrary continuous E for selection.

The exact 1000 Hz anchor is the one allowed computational grid insertion.

Published outputs are interpolated back to the original output grid.


======================================================================
16. REGION DEFINITIONS
======================================================================

The final output has exactly three conceptual regions.

REGION A:

    f <= H

Output:

    BaseTarget

REGION B:

    H < f <= E

Output:

    monotone cubic Hermite bridge

REGION C:

    f > E

Output:

    Masked EarPrint

No additional correction or blending operation is allowed after E.


======================================================================
17. FAIL-SAFE
======================================================================

If no candidate E satisfies every mandatory hard gate:

    status = NO_STABLE_HANDOFF

The engine MUST then return:

    BaseTarget

No forced transition is permitted.

The engine MUST NOT relax gates or select an arbitrary fallback E.


======================================================================
18. DETERMINISM
======================================================================

For identical:

    - frequency grid
    - BaseTarget
    - Masked EarPrint
    - configuration

the engine MUST produce the same:

    H

    E

    output

    diagnostics

on every run.

No randomisation is permitted.


======================================================================
19. VERTICAL TRANSLATION INVARIANCE
======================================================================

Adding a constant vertical offset C to both source curves must not alter:

    H

    E

    transition width

    feasibility

The resulting output must satisfy:

    Output' = Output + C

within numerical precision.


======================================================================
20. POSITIVE SCALE INVARIANCE
======================================================================

Multiplying both source curves by a positive constant A must preserve the
same geometric decision and scale the output consistently.


======================================================================
21. NEGATIVE SCALE
======================================================================

Negative scaling is not a physically meaningful dB-domain transformation
and is not part of the production invariance contract.


======================================================================
22. NO STITCHING
======================================================================

The handoff MUST NOT stitch unrelated target curves.

There is only one BaseTarget and one Masked EarPrint.


======================================================================
23. NO TARGET AVERAGING
======================================================================

The handoff MUST NOT average target families.

Target selection occurs upstream.

The handoff engine is target-agnostic.


======================================================================
24. NO PSYCHOACOUSTIC TARGET OPTIMISATION
======================================================================

Psychoacoustic research may justify the need for smooth transitions and
avoidance of artificial extrema, but it MUST NOT become a hidden target-
specific selection weight.

31. FINAL MATHEMATICAL LOCK
======================================================================

For:

    1000 < f <= E

let:

    Delta = MaskedEarPrint(E) - BaseTarget(1000)

    L = log2(E / 1000)

and let the raw endpoint slopes be retained exactly, with:

    alpha = d0_raw*L/Delta >= 0

    beta  = d1_raw*L/Delta >= 0

    alpha + beta <= 3

A candidate that violates any of these conditions is rejected; endpoint
slopes are never clipped or rescaled.

The output is the cubic Hermite bridge between:

    BaseTarget(1000)

and:

    MaskedEarPrint(E)

with the exact analytic derivative gate described above.

For:

    f <= 1000

the output is exactly:

    BaseTarget

For:

    f > E

the output is exactly:

    Masked EarPrint

If no valid E exists:

    output = BaseTarget

    status = NO_STABLE_HANDOFF

This constitutes the locked boundary-handoff specification.
